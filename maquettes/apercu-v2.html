À trancherCe qui ne fait pas sens aujourd'hui

1 · Le lien « Questions fréquentes » flotte sous le bonjour. Une question se pose en regardant ses chiffres, pas un en-tête de page. Ma proposition : il rejoint l'onglet Aide, qui existe déjà.
2 · Le chemin de démarrage (« Complétez votre profil… ») peut s'afficher à une ancienne. Tant qu'une étape reste inachevée, il occupe le haut de l'aperçu. Proposé : le déplacer dans Paramètres, où ces étapes se règlent.
3 · Le panneau de lien répète le code une fois que celui-ci est en haut. Proposé : le panneau ne montre plus que l'URL de partage, le code vit en haut et nulle part ailleurs.
4 · Le widget « Partagez ces produits » est un outil de vente posé en fin d'aperçu, après l'identité et la carte. Proposé : le garder, mais en dernier, sous le lien — c'est déjà le cas — ou le déplacer dans Performance si tu le juges plus marketing que bilan.
